Proveedores admite subcategorías.

Cada categoría tiene palabras clave: al importar el listado de ventas, todo ítem cuya descripción contenga alguna de esas palabras se suma ahí. Ej: "excellent" → Alimento, "perfos pipeta" → Pipetas.

Descargá un archivo con todos los movimientos, ingresos y categorías. Guardalo para no perder información si cambiás de computadora o navegador.

Importá un archivo de copia previamente exportado. Esto reemplaza los datos actuales de esta computadora.

Historial de importaciones

Cada vez que importás un Excel (de gastos o de ingresos) queda un registro acá. Si algo se cargó mal, deshacés esa importación puntual sin tocar el resto de los datos.

Borrar todos los datos
